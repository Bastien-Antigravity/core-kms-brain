# 📚 The 5‑Dimensional Hybrid System (PARA + Diátaxis + Zettelkasten)

## 🎯 Goal
Maintain and automatically correct the markdown documentation throughout the **obsidian‑brain** vault, ensuring it conforms to the five dimensions:
1. **Physical (PARA)** – shallow folder hierarchy and clear separation of Projects, Areas, Resources, Archives.
2. **Dimensional (Tags)** – consistent, cross‑cutting tag taxonomy for fast filtering.
3. **Algorithmic (YAML + Dataview)** – each file starts with a proper YAML front‑matter block enabling queryable metadata.
4. **Visual (Canvas)** – generate or update `.canvas` maps for complex relationships.
5. **Conceptual (Zettelkasten)** – enforce bidirectional linking and atomic note size limits.

## 📂 Physical (PARA)
* Scans the entire vault (including sub‑modules) for files that violate the shallow‑folder rule (e.g., deep nesting > 3 levels) and reports them.
* Suggests moving files into the appropriate top‑level folder (`01‑Project‑Business`, `02‑Project‑Architecture`, etc.).

## 📑 Dimensional (Tags)
* Validates that every markdown file contains at least one tag from the **canonical taxonomy** (`tags.yaml`).
* Normalises missing `#` prefixes and warns on unknown categories.

## 🗂️ Algorithmic (YAML + Dataview)
* Ensures a minimal YAML front‑matter block is present. If absent, injects the default block:
```yaml
---
microservice: <folder‑name>
type: note
status: draft
tags:
  - "#service/<folder‑name>"
  - "#type/note"
---
```
* Updates existing front‑matter to include any new required fields (`status`, `tags`).

## 🎨 Visual (Canvas)
* Generates or updates a top‑level `Ecosystem-Map.canvas` that visualises the relationship between the five dimensions and key documentation areas.
* Adds links from each canvas node to the underlying markdown files.

## 📚 Conceptual (Zettelkasten)
* Detects files larger than **200 lines** and proposes atomic splitting.
* Inserts bidirectional [[00-AI-Orchestration/README|link]] references to related notes (e.g., linking a playbook to its corresponding architecture ADR).
